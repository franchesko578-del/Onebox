# ONEBOX implementation roadmap

## Phase 1 — Starter foundation (included)
- Monorepo structure
- Telegram initData validation
- Worker + D1 schema
- Basic dashboard
- QR code preview and metadata save
- Personal notes create/list
- Workspace create/list
- Telegram command webhook

## Phase 2 — QR Studio Maximum
- Advanced editor: foreground/background, gradient, eyes/dots, logo, frame
- PNG/SVG export
- Static/dynamic QR distinction
- Dynamic QR edit/disable/expiry/password
- Scan analytics and privacy controls
- CSV import, batch generation and ZIP export
- QR collections and validation scanner

## Phase 3 — NoteSpace Personal
- Rich text editor
- Folders, tags, colors, pin, archive, trash
- Search and version history
- Checklist and tasks
- Calendar and recurring reminders
- PDF/TXT export

## Phase 4 — NoteSpace Team
- Workspace invites
- Owner/admin/editor/viewer permissions
- Shared notes and checklists
- Comments and activity log
- Membership management
- Permission and isolation tests

## Phase 5 — Production readiness
- R2 uploads with signed access
- Rate limiting and abuse prevention
- Data export and account deletion
- Monitoring, backups and restore drills
- Accessibility and mobile testing
- Privacy policy and terms
